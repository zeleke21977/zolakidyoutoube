# Butterfly Workout Video Frame (React + Vite)

    npm install
    npm run dev      # open the localhost link it prints (use Chrome or Edge)
    npm run build    # production build in dist/

Files: src/App.jsx (UI + state), src/lib.js (timeline/time logic), src/draw.js (canvas export), src/assets (butterfly + logo).

Use **Menu → Music & audio** (or **Add audio**) to add one or more audio files. Tracks default to the beginning of the timeline at 70% volume, with 1-second fades. Adjust each track's start/end time, volume, and fades; playback and downloaded video include the timed audio mix.
